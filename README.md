# XignAll

**XignAll** is a desktop application for bulk PDF digital signing with precise placement, preparation, and verification — 100% offline, no server, no cloud.

## Download

Go to the [Releases](https://github.com/LiviuStoica73/XignAll-releases/releases) page to download the latest version.

| Platform | File | Requirements |
|----------|------|--------------|
| macOS | XignAll-mac.dmg | macOS 12+ (Intel + Apple Silicon) |
| Windows | XignAll-win.exe | Windows 10/11 (x64) |
| Linux | XignAll-linux.tar.gz | Ubuntu 22.04+ / Debian 12+ (x86_64) |

## Features

- Bulk PDF signing with PKCS#12 (.p12) and PKCS#11 (hardware tokens / USB)
- Precise visual signature placement on coordinates
- Document preparation: DOCX / ODT / XLSX to PDF via LibreOffice
- Signature verification with trust chain details
- PAdES-compliant signatures (B-level)
- Multi-language: Romanian / English
- Cross-platform workflow: signing profiles work identically on macOS, Windows and Linux
